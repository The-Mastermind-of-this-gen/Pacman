## Description
A faithful clone of the classic Pacman arcade game built with C++ and the CC212SGL graphics library. This project recreates the original Pacman gameplay with ghosts, pellets, and maze navigation while adding some modern touches like animated sprites and sound effects.

## Features
- Classic Pacman gameplay mechanics
- Animated Pacman character with directional sprites
- Ghost AI with different behaviors (Red and Inky ghosts implemented)
- Original maze design with portals
- Sound effects and music
- Loading screen and main menu
- Score tracking

## Installation
1. install the project as a .zip file
2. run the .sln file as administrator for the first time only
3. convert the vs architecture to x32 bit
4. disable the vs sdl security check

## Controls
- W/Up Arrow: Move Up
- A/Left Arrow: Move Left
- S/Down Arrow: Move Down
- D/Right Arrow: Move Right
- Enter: Select menu option
- F3: Toggle debug mode (shows collision matrix)

## How to Play
- Navigate Pacman through the maze to eat all the pellets
- Avoid the ghosts (Red and Inky)
- Use portals on either side of the screen to teleport
- The game ends when a ghost catches Pacman

## Dependencies
- Windows OS
- CC212SGL graphics library
- winmm.lib for sound effects
